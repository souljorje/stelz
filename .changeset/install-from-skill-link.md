You can now set up Stelz by sending a coding agent a link to the browser skill and asking it to install the skill. The agent installs Stelz instead of copying the skill file, registers the tools, and opens the Stelz UI. Then it tells you the next steps: create and start a profile, and start a new agent session. Agent setup no longer creates a profile or runs a browser check. The README shows the one-line request.

The browser skill is now one short procedure, with its recovery steps included. It links to the documentation for tool contracts, settings, and operator procedures, and the documentation links to the skill for agent behavior instead of repeating it.
