You can now set up Stelz by sending a coding agent a link to the browser skill with the request to install it. The skill tells the agent to install Stelz and connect its MCP tools, not to copy the skill file alone. After installation, the agent uses the installed copy of the skill. The README shows the one-line request.

The browser skill is now one short procedure, with its recovery steps included. It links to the documentation for tool contracts, settings, and operator procedures, and the documentation links to the skill for agent behavior instead of repeating it.
