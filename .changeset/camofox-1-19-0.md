Camofox is now version 1.19.0. The 18 MCP tools and their guarantees are the same.

Stelz exposes only the nine reviewed browser tools. Stelz selects the profile and the tab group for each call. `camofox_click` accepts the new optional checks `expected_role` and `expected_accessible_name`.

Camofox 1.19.0 can restart a browser that has a session, close a crashed tab, and resize a popup. Stelz keeps these actions off.
