# Stelz logos

| Asset | Use |
| --- | --- |
| `stelz-logo-full.svg` | Full logo with black artwork for light backgrounds. |
| `stelz-logo-full-dark.svg` | Full logo with white artwork for dark backgrounds. |
| `stelz-logo.svg` | Small mark for icons and compact spaces. |
| `favicon.svg` | Small mark that follows the browser's light or dark theme. |

The two original SVG files preserve the supplied artwork.
The dark variant changes only the fill color.
The UI uses the original files as CSS masks. Its theme controls their color.
The project README uses GitHub's supported [`picture` element](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/quickstart-for-writing-on-github#adding-an-image-to-suit-your-visitors) to select the full logo.
